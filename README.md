# React Native Aplikacija

Paprasta, veikianti React Native aplikacija naudojant Expo.

## Diegimas

```bash
npm install
```

## Paleidimas

```bash
# Pradėti darbą
npm start

# iOS
npm run ios

# Android
npm run android

# Web
npm run web
```

Šios komandos jums atidaryti Expo CLI, kurioje galite pasirinkti platformą.

## Struktūra

- `App.js` - Pagrindinė aplikacijos komponentė
- `app.json` - Expo konfiguracija
- `package.json` - Projektui reikalingos priklausomybės
